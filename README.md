# Tech Academy Website

A responsive educational website developed as a web development project using **HTML, CSS, and JavaScript**.

The website presents a fictional technology academy, its available courses, events, and team members. It also includes several JavaScript-based interactive features.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Navigation between the main pages
* Course catalogue with course descriptions
* Events page with upcoming events
* Team/contact page
* Contact form with JavaScript interaction
* Basic text search functionality
* Dynamic "Back to Top" button
* Interactive page elements using JavaScript
* Responsive layouts using CSS media queries

## Technologies

* **HTML5** — page structure and semantic elements
* **CSS3** — styling, layouts, animations, and responsive design
* **JavaScript** — DOM manipulation, event handling, form interaction, and dynamic functionality


## Responsive Design

The website uses CSS media queries to adapt the layout to different screen sizes, including:

* Desktop
* Tablet
* Mobile
* Mobile landscape orientation

The goal was to maintain a usable and consistent layout across different devices.

## JavaScript Functionality

JavaScript is used to add interactive functionality to the website, including:

* Handling user interactions
* Contact form processing
* Search functionality
* Scroll-based "Back to Top" button
* Dynamic changes to page elements

## Purpose

This project was created to practice the fundamentals of front-end web development and to gain experience working with HTML, CSS, and JavaScript together.
